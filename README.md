# Legerly

Desktop inventory and ledger management app built with Electron, React, Vite, and SQLite.

## Requirements

- Node.js 20+
- npm 10+
- Windows is currently the primary packaged target

## Development

```bash
npm install
npm run dev
```

## Quality Checks

```bash
npm run type-check
npm run lint
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```
