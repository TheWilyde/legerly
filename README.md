# Legerly

Desktop inventory and ledger management app built with Electron, React, Vite, and SQLite.

## Requirements

- Node.js 20+
- npm 10+
- Windows is currently the primary packaged target

## Development

```bash
pnpm install
pnpm run dev
```

## Quality Checks

```bash
pnpm run type-check
pnpm run lint
```

## Build

```bash
pnpm run build
```

## Test

```bash
pnpm test
```
